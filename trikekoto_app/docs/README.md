The two HTML files are also published as live artifacts, which is where they
are edited. These copies exist because an artifact is not a backup: it lives
outside the repository, and a thesis deliverable that exists in exactly one
place is one accident from gone.

Re-copy them from the published version when they change, rather than editing
the HTML here by hand — otherwise the two drift and neither is authoritative.
